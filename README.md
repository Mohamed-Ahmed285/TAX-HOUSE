# IAC - Taxes House

موقع شركة IAC - شركة متخصصة في المحاسبة، الضرائب، والمراجعة.

## المميزات

- تصميم عصري واحترافي
- دعم كامل للغة العربية (RTL)
- متجاوب مع جميع الأجهزة
- أنيميشن سلس باستخدام Framer Motion
- نظام ألوان احترافي (Navy & Gold)
- صفحات: الرئيسية، تسجيل الدخول، إنشاء حساب

## التقنيات المستخدمة

- Next.js 14
- React 18
- TailwindCSS
- Framer Motion

## التثبيت والتشغيل

```bash
# تثبيت المكتبات
npm install

# تشغيل المشروع في وضع التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build

# تشغيل المشروع بعد البناء
npm start
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## الصفحات

- `/` - الصفحة الرئيسية
- `/login` - صفحة تسجيل الدخول
- `/signup` - صفحة إنشاء حساب جديد

## المكونات

- `Navbar` - شريط التنقل العلوي
- `Footer` - التذييل
- `Hero` - قسم البطل الرئيسي
- `About` - قسم عن الشركة
- `Services` - قسم الخدمات
- `Clients` - قسم العملاء
- `Contact` - قسم التواصل
